# Mamba-TransQR v1.0.2 release notes

Mamba-TransQR v1.0.2 is the final documentation-only reproducibility
synchronization patch prepared for the PeerJ Computer Science AI Application
resubmission. It introduces no scientific change.

## Changed

- Finalized the README's post-publication wording.
- Synchronized package, citation, and reproducibility version metadata at
  version 1.0.2.
- Documented the already published Mamba-TransQR v1.0.1 Zenodo archival record,
  DOI `10.5281/zenodo.22874149`.
- Removed obsolete pre-publication and pending-DOI wording for v1.0.1.
- Prepared a publication-stable README that does not depend on a future v1.0.2
  Zenodo DOI.

## Unchanged

- Scientific experiments and experimental protocol.
- Model architecture and implementation.
- Dataset lineage and authoritative dataset manifest.
- Trained Phase 3 and ablation checkpoints.
- Reported PSNR, SSIM, latency, and ablation results.
- Figures, tables, and manuscript-supporting quantitative data.
- Scientific interpretations and conclusions.
- Dataset and checkpoint/model-weight license status; neither is separately
  documented.

## Release lineage

- v1.0.0 is the frozen scientific release at commit
  `781bbbd39fbea517f6481e78f837a5e6989d3232`, archived at Zenodo DOI
  `10.5281/zenodo.21913175`.
- v1.0.1 is the preceding documentation-only reproducibility release, archived
  at Zenodo DOI `10.5281/zenodo.22874149`.
- v1.0.2 synchronizes final PeerJ documentation. It does not rerun experiments,
  replace scientific artifacts, or reinterpret the v1.0.0 results.
